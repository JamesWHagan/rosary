# Contributing

Thank you for wanting to help! This project is a gift: a free place for people to pray for one another. Contributions of any size are welcome.

## Good ways to help

- **Translations** of the prayers and the interface, especially Italian, Sinhala, Tamil, Spanish and Portuguese. Please use the approved liturgical wording of your language, and say where it comes from.
- **Checking prayer texts** for accuracy.
- **Accessibility**: screen readers, contrast, text size.
- **Bug reports**: open an issue with your phone model, browser and what happened.

## How to contribute

1. **Open an issue first** for anything bigger than a small fix, so we can agree on it before you spend time.
2. **Fork** this repository and make your change on a new branch.
3. **Open a pull request** describing what you changed and why. Screenshots from a phone help a lot.
4. The maintainer reviews every pull request before it goes live. Nothing reaches the site without approval.

## Ground rules

- Keep it **free**: no ads, tracking, analytics that identify people, or paid features.
- Keep it **simple**: plain HTML, CSS and JavaScript with no build step, unless there's a strong reason.
- **Never commit secrets.** The Supabase anon/public key is fine, because the database's security rules protect the data. Never commit a `service_role` key or any password.
- **Respect people's intentions.** Never copy real submitted intentions into issues, pull requests or test data.
- Be kind. This is a place of prayer.
